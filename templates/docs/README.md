# Documentation Index

This docs folder is the source of truth for project status and implementation history.

## Canonical Docs

- `ENVIRONMENT_INVENTORY.md`: current runtime/system state
- `IMPLEMENTATION_LOG.md`: chronological record of meaningful changes

## Update Policy

1. Update `IMPLEMENTATION_LOG.md` for every meaningful infra/code/process change.
2. Update `ENVIRONMENT_INVENTORY.md` whenever live state changes.
3. Keep doc updates in the same commit as the corresponding change.
